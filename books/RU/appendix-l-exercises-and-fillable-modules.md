## Упражнение 5 — Оцените один риск

**Задание:** Для выбранной задачи назовите, что может пойти не так. Оцените каждое по Вероятности и Последствиям. Используйте матрицу: Высокая×Высокие = Критический; Средняя×Высокие = Высокий; Низкая×Низкие = Низкий. (Полная матрица в Приложении H.)

| Риск | Что может пойти не так | Вероятность | Последствия | Уровень риска | Меры снижения | Ответственный |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |

**Правило:** Каждый Критический или Высокий риск требует меры снижения **и** названного ответственного до запуска. Мера снижения без ответственного — не мера снижения.
