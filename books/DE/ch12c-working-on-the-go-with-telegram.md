# Unterwegs arbeiten mit Telegram

Wenn Sie Telegram ohnehin jeden Tag nutzen, kann Ihr Assistent zu Ihnen dazukommen. Sie fragen im selben Chat, den Sie mit Ihrem Team benutzen, und der Agent antwortet, schickt Dateien und hält alle informiert. Keine neue App, die Sie lernen müssen.

### Ihr Assistent in Telegram

![Ein Gespräch mit dem Agenten in Telegram](../../assets/examples/chat-on-the-go.png)
*Ein Gespräch mit dem Agenten in Telegram*

**Was Sie fragen:** `(telegram) Wie viel haben wir gestern verkauft?`

Der Agent antwortet in Ihrem Telegram-Chat, ganz wie ein Kollege. Stellen Sie eine Frage, erhalten Sie die Antwort, machen Sie weiter.

*Tipp: Der Zugang zu Telegram nutzt eine Freigabeliste, daher können nur die Personen mit ihm sprechen, die Sie auswählen.*

---

### Ein Dokument auf Ihrem Telefon abrufen

![Ein Dokument, das in den Telegram-Chat geschickt wird](../../assets/examples/send-a-file.png)
*Ein Dokument, das in den Telegram-Chat geschickt wird*

**Was Sie fragen:** `(telegram) Schick mir die Rechnung, die du für Bright Cafe gemacht hast.`

Der Agent schickt die Datei in Ihren Telegram-Chat. Öffnen Sie sie, leiten Sie sie weiter oder laden Sie sie herunter — direkt von Ihrem Telefon.

*Tipp: Sie können jedes Dokument anfordern, das Sie früher erstellt haben, und es sich schicken lassen.*

---

### Der Assistent in der Gruppe Ihres Teams

![Der Agent beantwortet Fragen in einer Team-Gruppenchat](../../assets/examples/team-group.png)
*Der Agent beantwortet Fragen in einer Team-Gruppenchat*

**Was Sie fragen:** `(telegram group) Was sind die heutigen Lieferstopps?`

Der Agent kommt in die Gruppe und beantwortet die Fragen des Teams mit den geteilten Informationen, sodass niemand das laufende Lexikon sein muss.

*Tipp: Sie bestimmen, wer in die Gruppe darf und was der Agent teilen darf.*


## Wichtige Punkte

- Sie können eine Aufgabe einmal einrichten und AgentBridge sie ausführen lassen, mit ihm sprechen oder ihn per Telefon und Telegram erreichen.
- Das Ergebnis ist dieselbe fertige Arbeit, die Sie auf den Bildern sehen, geliefert dorthin, wo Sie gerade sind.
- Sie behalten die Kontrolle: Sie wählen die Zeit, den Ort und wer ihn benutzen darf.
