# Anhang L — Übungen und ausfüllbare Module

Kurze Übungen, die aus dem Lesen ein Tun machen. Mache sie mit Stift oder auf dem Bildschirm. Jede dauert 10–20 Minuten. Sie folgen den Hauptthemen des Buchs. Mache sie der Reihe nach, oder wähle die, die du brauchst. Es gibt keine falschen Antworten — nur leere Seiten.

## Übung 1 — Liste deine automatisierbaren Aufgaben

**Prompt:** Schreibe jede wiederkehrende Aufgabe auf, die dein Team macht. Eine Aufgabe ist ein Kandidat für Automatisierung, wenn sie oft gemacht wird, Schritten folgt und nicht jedes Mal tiefes Urteilsvermögen braucht.

| Aufgabe | Wie oft | Wer macht sie | Folgt festen Schritten? (J/N) | Braucht menschliches Urteilsvermögen? (J/N) |
|---|---|---|---|---|
|  |  |  |  |  |
|  |  |  |  |  |
|  |  |  |  |  |
|  |  |  |  |  |
|  |  |  |  |  |
|  |  |  |  |  |

**Faustregel:** Hohe Häufigkeit + feste Schritte + wenig Urteilsvermögen = bester erster Kandidat. Aufgaben mit hohem Urteilsvermögen bleiben bei Menschen; lass KI unterstützen, nicht entscheiden.

**Deine Top-3-Kandidaten:** 1) ______ 2) ______ 3) ______

## Übung 5 — Bewerte ein Risiko

**Prompt:** Nenne für deine gewählte Aufgabe, was schiefgehen könnte. Bewerte jedes nach Wahrscheinlichkeit und Auswirkung. Nutze die Matrix: Hoch×Hoch = Kritisch; Mittel×Hoch = Hoch; Niedrig×Niedrig = Niedrig. (Volle Matrix in Anhang H.)

| Risiko | Was könnte schiefgehen | Wahrscheinlichkeit | Auswirkung | Risikograd | Maßnahme | Verantwortlicher |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |

**Regel:** Jedes kritische oder hohe Risiko braucht vor dem Start eine Maßnahme **und** einen benannten Verantwortlichen. Eine Maßnahme ohne Verantwortlichen ist keine Maßnahme.
