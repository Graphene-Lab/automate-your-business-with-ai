# A Note About the Tool Behind This Book

This book explains how a small business can use Artificial Intelligence (AI) in simple
words. It talks about documents, spreadsheets, reports, email, research, and tasks that
run on their own.

Every one of these things can be done today with one tool: **AgentBridge**.

AgentBridge is an AI office assistant made by Graphene Lab. You talk to it in plain
words, and it does the work. It writes real documents, builds spreadsheets and charts,
sends and reads email, researches the web, and makes presentations. It can also run a
task on a time you agree on, answer by voice or phone, and work inside Telegram. It runs
on your own computer, so your files stay with you.

Throughout this book you will see pictures of real results made with AgentBridge, and the
one line of text a person typed to get them. You do not need to install anything to read
this book. But if you want to try the tool yourself, start here.
