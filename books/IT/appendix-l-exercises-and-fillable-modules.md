# Appendice L — Esercizi e moduli da compilare

## Esercizio 5 — Valuta un rischio

**Traccia:** Per il compito scelto, nomina cosa potrebbe andare storto. Valuta ciascuno per Probabilità e Impatto. Usa la griglia: Alta×Alta = Critico; Media×Alta = Alto; Bassa×Bassa = Basso. (Griglia completa in Appendice H.)

| Rischio | Cosa potrebbe andare storto | Probabilità | Impatto | Livello di rischio | Mitigazione | Responsabile |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |

**Regola:** Ogni rischio Critico o Alto ha bisogno di una mitigazione **e** di un responsabile nominato prima del lancio. Una mitigazione senza responsabile non è una mitigazione.
