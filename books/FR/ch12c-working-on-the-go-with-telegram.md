# Travailler en déplacement avec Telegram

Si vous utilisez déjà Telegram tous les jours, votre assistant peut vous y rejoindre. Vous posez votre question dans le même chat que celui de votre équipe, et l'agent répond, envoie des fichiers et tient tout le monde au courant. Pas de nouvelle application à apprendre.

### Votre assistant dans Telegram

![Une conversation avec l'agent dans Telegram](../../assets/examples/chat-on-the-go.png)
*Une conversation avec l'agent dans Telegram*

**Ce que vous demandez :** `(telegram) Combien avons-nous vendu hier ?`

L'agent répond dans votre chat Telegram, comme un collègue. Posez une question, obtenez la réponse, continuez votre route.

*Conseil : L'accès à Telegram fonctionne avec une liste d'autorisation, donc seules les personnes que vous choisissez peuvent lui parler.*

---

### Recevoir un document sur votre téléphone

![Un document livré dans le chat Telegram](../../assets/examples/send-a-file.png)
*Un document livré dans le chat Telegram*

**Ce que vous demandez :** `(telegram) Envoie-moi la facture que tu as faite pour Bright Cafe.`

L'agent envoie le fichier dans votre chat Telegram. Ouvrez-le, transférez-le ou téléchargez-le, directement depuis votre téléphone.

*Conseil : Vous pouvez demander n'importe quel document créé auparavant et vous le faire envoyer.*

---

### L'assistant dans le groupe de votre équipe

![L'agent qui répond dans un chat de groupe d'équipe](../../assets/examples/team-group.png)
*L'agent qui répond dans un chat de groupe d'équipe*

**Ce que vous demandez :** `(telegram group) Quels sont les arrêts de livraison d'aujourd'hui ?`

L'agent rejoint le groupe et répond aux questions de l'équipe avec les informations partagées, pour que personne n'ait à être l'encyclopédie vivante.

*Conseil : Vous contrôlez qui est autorisé dans le groupe et ce que l'agent peut partager.*


## Points à retenir

- Vous pouvez configurer un travail une fois et laisser AgentBridge l'exécuter, lui parler, ou y accéder par téléphone et Telegram.
- Le résultat est le même travail fini que vous voyez dans les images, livré là où vous êtes.
- Vous gardez le contrôle : vous choisissez l'heure, le lieu, et qui peut l'utiliser.
