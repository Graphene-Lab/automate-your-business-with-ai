# Annexe L — Exercices et modules à remplir

De courts exercices pour transformer la lecture en action. Faites-les avec un stylo ou à l'écran. Chacun prend 10 à 20 minutes. Ils suivent les grands thèmes du livre. Faites-les dans l'ordre, ou choisissez ceux dont vous avez besoin. Il n'y a pas de mauvaises réponses — seulement des pages blanches.

## Exercice 1 — Listez vos tâches automatisables

**Prompt :** Écrivez toutes les tâches répétées que fait votre équipe. Une tâche est candidate à l'automatisation si elle est faite souvent, suit des étapes, et n'exige pas un jugement profond à chaque fois.

| Tâche | À quelle fréquence | Qui la fait | Suit des étapes fixes ? (O/N) | Exige un jugement humain ? (O/N) |
|---|---|---|---|---|
|  |  |  |  |  |
|  |  |  |  |  |
|  |  |  |  |  |
|  |  |  |  |  |
|  |  |  |  |  |
|  |  |  |  |  |

**Règle pratique :** Haute fréquence + étapes fixes + peu de jugement = meilleur premier candidat. Les tâches à fort jugement restent aux humains ; laissez l'IA assister, pas décider.

## Exercice 5 — Évaluez un risque

**Prompt :** Pour la tâche choisie, nommez ce qui pourrait mal tourner. Notez chacun sur Probabilité et Impact. Utilisez la grille : Élevé×Élevé = Critique ; Moyen×Élevé = Élevé ; Faible×Faible = Faible. (Grille complète en Annexe H.)

| Risque | Ce qui pourrait mal tourner | Probabilité | Impact | Niveau de risque | Mesure d'atténuation | Responsable |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |

**Règle :** Chaque risque Critique ou Élevé exige une mesure d'atténuation **et** un responsable nommé avant le lancement. Une atténuation sans responsable n'est pas une atténuation.
