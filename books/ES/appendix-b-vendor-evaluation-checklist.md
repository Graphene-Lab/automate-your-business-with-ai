# Apéndice B — Lista de verificación para evaluar a un proveedor de IA

Usa esto antes de firmar con cualquier proveedor de IA. Trabaja tema por tema. Si un proveedor no puede responder una pregunta con claridad, tómalo como una advertencia. Escribe un **Sí / No / Desconocido** junto a cada elemento. Una larga lista de "Desconocido" es en sí misma una respuesta.

## 1. Qué hace realmente la herramienta

- [ ] El proveedor puede decir, en palabras simples, el único problema que resuelve para mí.
- [ ] Encaja en un proceso real que yo tengo, no en un vago "puede hacer de todo".
- [ ] La he visto funcionar con mi tipo de datos, no solo en una demo pulida.
- [ ] Sé lo que **no** hace, y dónde falla.
- [ ] El resultado es algo que puedo verificar para comprobar si es correcto.

## 2. Datos y privacidad

- [ ] Sé exactamente qué datos recoge y almacena la herramienta.
- [ ] Sé dónde se almacenan los datos (qué país / región).
- [ ] Mis datos **no** se usan para entrenar el modelo compartido del proveedor a menos que yo lo apruebe por escrito.
- [ ] Puedo borrar mis datos y obtener prueba del borrado.
- [ ] El proveedor explica cómo maneja los datos personales y sensibles.
- [ ] Los datos están cifrados tanto almacenados como en movimiento.

## 3. Seguridad

- [ ] La herramienta admite un inicio de sesión fuerte (autenticación de múltiples factores).
- [ ] El acceso se controla por persona, para que no todos vean todo.
- [ ] Hay un registro de quién hizo qué, que yo puedo revisar.
- [ ] El proveedor tiene una política de seguridad escrita que puedo leer.
- [ ] El proveedor me informa sobre las brechas con prontitud (una promesa clara de notificación).
- [ ] Sé cómo se protegen contra ataques comunes (por ejemplo, inyección de prompt en herramientas que leen texto externo).

## 4. Cumplimiento (RGPD y Ley de IA de la UE)

- [ ] El proveedor puede decir cómo cumple con el RGPD.
- [ ] Si mi uso es de mayor riesgo bajo la Ley de IA de la UE, el proveedor respalda las obligaciones extra (registros, supervisión humana, transparencia).
- [ ] Ofrecen un acuerdo de tratamiento de datos (el contrato estándar que pide el RGPD).
- [ ] Pueden apoyar una DPIA si mi proyecto la necesita.
- [ ] Me dicen si usan subencargados (otras empresas que manejan mis datos).

## 5. Precios

- [ ] El precio es claro, sin extras ocultos.
- [ ] Entiendo cómo crece el costo si crece el uso (¿por usuario? ¿por tarea? ¿por mensaje?).
- [ ] Sé qué pasa si supero los límites de mi plan.
- [ ] Sé el precio de renovación, no solo el precio de introducción.
- [ ] Hay un nivel más barato que aun así cubre mi necesidad principal.

## 6. Soporte y servicio

- [ ] Hay un canal de soporte real (correo, chat, teléfono) con horario indicado.
- [ ] Los tiempos de respuesta están escritos, no prometidos de palabra.
- [ ] Hay ayuda para empezar (incorporación, guías, capacitación).
- [ ] La herramienta tiene un compromiso de disponibilidad indicado (una promesa de fiabilidad).
- [ ] Puedo contactar a una persona cuando importa.

## 7. Contrato y salida

- [ ] Puedo cancelar sin una penalización pesada.
- [ ] Puedo exportar todos mis datos en un formato utilizable en cualquier momento.
- [ ] Sé con cuánta antelación hay que avisar para cancelar.
- [ ] La duración del contrato es razonable para un primer compromiso.
- [ ] He pensado en el encierro (lock-in): ¿qué tan difícil es irse más tarde?
- [ ] Mantengo la propiedad de mis propios datos y contenido.

## 8. Confianza y reputación

- [ ] He comprobado referencias o reseñas de negocios como el mío.
- [ ] La empresa ha operado el tiempo suficiente como para ser responsable.
- [ ] Sé a quién contactar si algo sale mal.
- [ ] Sus afirmaciones son creíbles, no exageradas.

## 9. Prueba y demostración

- [ ] Puedo hacer una pequeña prueba antes de comprometerme.
- [ ] Definí cómo se ve el "éxito" para la prueba.
- [ ] La probé con mis datos reales, no solo con datos de muestra.
- [ ] Sé la fecha en que decidiré: continuar, cambiar o parar.

## Tarjeta de puntuación rápida

Suma tus respuestas:

| Resultado | Significado |
|--------|---------|
| Mayoría **Sí** | Buen candidato. Pasa a un pequeño piloto. |
| Varios **No** en datos, seguridad o salida | Alto riesgo. Pide más o aléjate. |
| Muchos **Desconocido** | El proveedor no es transparente. Tómalo como una señal de alarma. |

**Regla práctica:** Nunca cambies el control de tus datos por conveniencia. Si el proveedor no responde con claridad, esa es tu respuesta.
