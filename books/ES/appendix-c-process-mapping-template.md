# Apéndice C — Plantilla para mapear tus procesos

Antes de automatizar cualquier cosa, anota lo que realmente haces. Esta plantilla captura una fila por proceso. Rellénala para tus 5–10 tareas repetidas principales. No puedes mejorar lo que no has mapeado.

## Cómo usarla

1. Enumera las tareas que tu equipo repite cada semana.
2. Para cada una, rellena una fila abajo. Sé honesto sobre el tiempo y la molestia.
3. Marca **Potencial de automatización**: Alto (aburrido, basado en reglas, gran volumen), Medio (parcialmente automático), Bajo (necesita criterio humano).
4. Empieza por las filas de alto potencial y alta molestia.

## Guía de columnas

- **Nombre del proceso** — Una etiqueta corta y clara que cualquiera entendería.
- **Responsable** — La única persona responsable de este proceso hoy.
- **Pasos** — Acciones numeradas, en orden. Mantén cada paso en una sola acción.
- **Entradas** — Lo que entra: documentos, correos, formularios, datos.
- **Salidas** — Lo que sale: un registro, una respuesta, un archivo, una decisión.
- **Tiempo por ejecución** — Los minutos reales que tarda, no lo que te gustaría que tardara.
- **Frecuencia** — Con qué frecuencia ocurre por día o semana.
- **Puntos de dolor** — Qué sale mal, qué es lento, qué la gente no soporta.
- **Potencial de automatización** — Alto / Medio / Bajo, con una razón si no es obvio.

## Consejos para un buen mapeo

- Mapea el proceso **tal como realmente es**, no como dice el manual.
- Pregunta a la persona que hace el trabajo, no a la que lo gestiona.
- Anota cada paso de "copiar y pegar" — esos son objetivos prime de automatización.
- Si un paso necesita confianza o criterio, márcalo para revisión humana.
- Suma el tiempo: `time per run × frequency` muestra a dónde van las horas cada semana.

## Procesos de alto potencial a buscar

Estos se repiten a menudo y siguen reglas claras — buenos primeros objetivos:

- Leer y clasificar correo o documentos entrantes.
- Copiar datos de un sistema a otro.
- Responder las mismas preguntas de clientes una y otra vez.
- Redactar respuestas, presupuestos o informes estándar.
- Revisar documentos buscando campos faltantes o erróneos.
- Resumir notas, llamadas o archivos largos.

Evita automatizar primero: cualquier cosa que necesite confianza, negociación o un criterio final sobre una persona.

## Cuadrícula de prioridad rápida

Ordena tus filas para elegir la primera cosa que automatizar.

| | Baja molestia | Alta molestia |
|---|---|---|
| **Alto potencial** | Bueno para después | **Empieza aquí** |
| **Bajo potencial** | Ignorar | Arregla el proceso primero, no con IA |

Elige una fila "Empieza aquí" para tu primer piloto. Mantenlo pequeño.

## Cómo estimar el tiempo con honestidad

- Cronometra la tarea una o dos veces de verdad; no adivines de memoria.
- Incluye los minutos ocultos: encontrar el archivo, cambiar de pantalla, corregir errores.
- Pregunta a dos personas que hagan la tarea y compara sus números.
- Usa una semana normal, no una tranquila.

## Usar el mapa

- El mapa muestra a dónde van las horas cada semana — esa es tu lista de objetivos.
- Un proceso con mucho tiempo y mucha molestia vale la pena automatizarlo primero.
- Si un proceso es doloroso pero de bajo volumen, arregla la causa antes de añadir herramientas.
- Mantén el mapa vivo: actualízalo cuando un proceso cambie. Es un documento de trabajo, no algo de una sola vez.
